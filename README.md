# SSB Defence Atlas

A comprehensive single-file study workbook for the SSB interview — Army, Navy, Air Force, Joint Defence, Global Security, and Personal Interview prep.

## Features

- Structured research leads for all topics (Army A1-A10, Navy N1-N9, Air Force F1-F9, Joint J1-J6, Global G1-G10, Neighbourhood P1-P5, Future Tech T1-T3, Personal Q1-Q6)
- **SSB Perspective** context block per topic — what angle the IO actually probes
- Enhanced research leads (⊕) with multi-dimensional angles: historical, technological, doctrinal, strategic, and current-affairs dimensions
- Cross-questions for verbal practice (no model answers — solve in your physical notes)
- Progress tracking with localStorage (survives browser refresh)
- Drill mode — 45-second verbal practice timer
- Bookmarks and topic notes
- Dark mode
- Print-friendly layout
- Works fully offline — no server, no internet, no CDN

## Usage

Open `index.html` in any browser. No installation needed.

## Study Method

1. Read the **Scope** block for the topic
2. Read the **SSB Perspective** block — understand what the IO is really testing
3. Work through **Research Leads** — look them up and write notes by hand
4. Attempt **Cross-Questions** verbally (or in your physical notebook)
5. Use **Drill Mode** to practise 45-second verbal answers
